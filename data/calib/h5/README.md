# h5 — transaction labels

Tabular records turned into text, kept because it is the one set here whose labels are neither human nor model-derived.

| | |
|---|---|
| Source | Kaggle [ealaxi/paysim1](https://www.kaggle.com/datasets/ealaxi/paysim1) (PaySim mobile-money simulator, Lopez-Rojas et al., EMSS 2016) |
| Licence | CC-BY-SA-4.0 |
| Label source | **simulated** — `isFraud` comes from the simulator's own rules, not from a person |
| Rows | 400 paysim_textualized |
| Split | assigned by the collector; `split_hint: null` (the source has no split) |

Rebuild, from the repository root:

```sh
python data/build/phase3_build_h5h6.py
```

SHA-256 of the rebuilt file:

```
a016d6274f11c9f0e6713012d176caeb61b991563a3f06fb5c92e6de4b8984e6  paysim_textualized.jsonl
```

**Reading the numbers.** The labels are generated by the simulator that generated the data, so they are perfectly consistent with it in a way real labels never are. Accuracy here is an upper bound on a task of this shape, not an estimate of field performance. Rebuilding needs a Kaggle API token, which is not stored in this repository.
